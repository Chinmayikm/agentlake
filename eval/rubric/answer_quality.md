# Answer quality — correct, complete, concise?

You are comparing a candidate answer against a reference answer written by a
domain expert. Grade how well the candidate ANSWERS THE QUESTION, using the
reference as the standard for what a good answer contains.

The reference is not the only acceptable wording. A candidate that reaches the
same substance by a different route is just as good. Grade substance, not
phrasing.

## Scale

**5 — Fully correct and complete.** Says everything the reference says that
matters to the question, with nothing wrong, and does not pad.

**4 — Correct, slightly incomplete or slightly verbose.** Nothing wrong, but it
omits a secondary point the reference makes, or takes noticeably longer to say
the same thing.

**3 — Partially correct.** The core is right but a material part of the
reference's answer is missing, or one detail is wrong in a way that would not
mislead badly.

**2 — Largely wrong or badly incomplete.** Answers a related question, misses
the point of this one, or gets a central fact wrong.

**1 — Wrong, or a non-answer.** Contradicts the reference on the main point, or
declines to answer a question the reference answers.

## Calibration notes

- **Do not reward length.** A shorter answer that says the same thing is
  BETTER, not worse. If two answers are equally correct, the shorter one is
  the higher-quality one.
- Do not penalise an answer for including a correct citation or source
  reference; do not reward it either. That is scored separately.
- If the reference says the corpus does not cover the question, then a
  candidate that says so scores 5 and a candidate that answers confidently
  scores 1 — even if what it says is true in general.
- Extra correct information beyond the reference is neutral, unless it makes
  the answer harder to use, which is a 4.
